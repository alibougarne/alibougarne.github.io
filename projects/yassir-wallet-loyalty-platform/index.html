Yassir Wallet & Loyalty Platform

Senior full stack developer

Client: Yassir

Nov 2018 – Jan 2020

As a senior full stack developer in a large Agile team I used ReactJS and NodeJS alongside Spring Boot and Material UI to build dynamic interfaces and RESTful APIs in a microservices architecture, turning design specifications into responsive applications that work across devices.

  • Wallet: a digital wallet for Yassir clients, interconnected with the company's other services (Food, Marketplace)
  • Vouchers and Fidelity: a system that retains customers by giving them points, which can be spent through the wallet or other services
  • Dashboards to manage and report on the services
  • A users management system (roles and permissions) for the dashboards
  • Design, development and testing of new applications, backend features, consumption of endpoints from ReactJS, and functional documentation

Stack: Microservices, Spring Boot, Spring Data, JPA, Hibernate, npm, MERN stack (MongoDB, Express, React, Node), Jest, TypeScript, Redux, TypeORM, Mongoose, PostgreSQL, Postman, Docker, GitHub, Scrum/ClickUp.
